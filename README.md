## ✨ Overview

**Python PDF Merger** is a lightweight Python project that combines multiple PDF files into a single document. It is useful for organizing documents, joining reports, and merging PDF pages quickly and easily.

## 🚀 Features

- 📑 Merge multiple PDF files into one document.
- 🔢 Maintain the order of the input files.
- ⚡ Simple and lightweight Python implementation.
- 🐍 Easy to install and run.
- 🛠️ Uses the `pypdf` library for PDF processing.

## 🧰 Technologies Used

- **Python** — Core programming language.
- **pypdf** — PDF reading and writing library.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/mshahidniazi/python-pdf-merger.git
```

### 2. Open the project folder

```bash
cd python-pdf-merger
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the Python script:

```bash
python PDF_merger.py
```

Follow the instructions in the terminal to merge your PDF files, according to the script's implementation.

## 💡 Example

Suppose you have these PDF files:

```text
sample1.pdf
sample2.pdf
```

After merging, you may get:

```text
merged_output.pdf
```

**Note:** The example filenames depend on how the script is configured. Place the input PDFs in the expected location before running the program.
